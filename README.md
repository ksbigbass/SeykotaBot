## About

TrendTracker is an automated trading system that identifies and trades high-momentum stocks using a trend-following strategy. The bot scrapes stock rankings from trend trading resources, maintains positions in the strongest performers, and automatically rebalances the portfolio as market leaders change.

**Key Features:**
- Automated stock screening and ranking
- Position sizing based on account balance (3% per position)
- Limit order execution via Alpaca API
- Daily P&L tracking
- Automatic position rotation based on momentum shifts

⚠️ **Disclaimer:** This is an educational project for paper trading. Not financial advice.
